# Research Archive

โฟลเดอร์นี้เก็บเอกสารค้นคว้า แหล่งอ้างอิง และ evidence ที่ใช้ประกอบการตัดสินใจทางเทคนิคของ Village Meeting AI โดยไม่แทนที่เอกสาร contract หรือ policy หลัก

## เอกสารปัจจุบัน

| เอกสาร | ใช้สำหรับ |
|---|---|
| [`STT-RESEARCH-ARCHIVE.md`](STT-RESEARCH-ARCHIVE.md) | แหล่งข้อมูลเปรียบเทียบ STT ภาษาไทย/long audio/diarization, วิธีทดลอง local และข้อจำกัดที่ตรวจสอบได้ |

## ลำดับการอ่าน

เริ่มจาก [`../FREE-STT-POLICY.md`](../FREE-STT-POLICY.md) เพื่อเข้าใจข้อกำหนด product จากนั้นอ่าน [`STT-RESEARCH-ARCHIVE.md`](STT-RESEARCH-ARCHIVE.md) เพื่อดูหลักฐานและแหล่งอ้างอิง อ่าน [`../STT-TECHNICAL-SPIKE.md`](../STT-TECHNICAL-SPIKE.md) เพื่อดูข้อสรุปเชิงสถาปัตยกรรม และตรวจสถานะงานล่าสุดใน [`../../PROGRESS.md`](../../PROGRESS.md)

เอกสารในโฟลเดอร์นี้ควรระบุวันที่ค้นคว้า ขอบเขต แหล่งอ้างอิง วิธีทดลอง และข้อจำกัดให้ชัดเจน ข้อมูลจาก model card หรือ provider documentation เป็นหลักฐานประกอบ ไม่ใช่ production guarantee และข้อมูลเสียงประชุมจริงต้องได้รับอนุญาตก่อนเก็บหรือใช้ทดสอบ
