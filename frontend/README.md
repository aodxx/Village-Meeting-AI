# Frontend

Reserved for the mobile-first PWA.

Implementation has not started yet because Phase 0 must first validate the long-form Thai speech-to-text architecture.

When implementation begins, this area will contain:

- Home
- Create Meeting
- Agenda
- Recording
- Processing
- Transcript
- AI Review
- Draft/Final Report
- Public Report
- Meeting History
- Settings

Frontend must follow `docs/UX-FLOW.md` and must never contain secrets or AI/API keys.
