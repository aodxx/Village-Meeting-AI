# Apps Script Backend

Reserved for the Google Apps Script Web App backend.

Planned responsibilities:

- API routing
- Google Sheets persistence
- Google Drive file management
- meeting state transitions
- speech-to-text orchestration
- Gemini structured analysis
- report/PDF generation
- public read-only report delivery

Secrets must be stored in Apps Script Properties and never committed to GitHub.

Implementation must follow:

- `docs/ARCHITECTURE.md`
- `docs/DATA-MODEL.md`
- `docs/API-CONTRACT.md`
